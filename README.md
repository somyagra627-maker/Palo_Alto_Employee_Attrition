\# Machine Learning-Based Employee Attrition Prediction and Risk Scoring System



\## Project Overview



This project develops a machine learning-based employee attrition prediction and risk scoring system for HR decision support.



The system predicts employee attrition probability, assigns employees to Low, Medium, and High risk categories, and provides model explainability using SHAP.



\## Case Study



Palo Alto Networks Employee Attrition Case Study



\## Domain



Human Resources Analytics / Machine Learning / Predictive Analytics



\## Models Used



\- Logistic Regression

\- Random Forest

\- XGBoost



\## Key Features



\- Employee attrition prediction

\- Probability-based risk scoring

\- Low / Medium / High risk classification

\- Feature importance analysis

\- SHAP explainability

\- Individual employee risk profiles

\- What-if risk simulation

\- Department-level risk analysis

\- Streamlit dashboard



\## Risk Categories



| Risk Level | Probability |

|---|---|

| Low Risk | < 30% |

| Medium Risk | 30%–60% |

| High Risk | > 60% |



\## Best Model



Logistic Regression was selected based on its stronger recall, F1-score and ROC-AUC performance for the attrition prediction objective.



\## Dashboard



The project includes an interactive Streamlit dashboard for HR decision support.
